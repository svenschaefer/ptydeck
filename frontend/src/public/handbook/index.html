Handbook/Manual

ptydeck Handbook

The handbook is split into two layers:

  • Operator guides for real workflows and decisions.
  • Generated reference for commands, API routes, and session-setting contracts.

Start Here

  • Use Startup and Sessions if you need to create terminals, move around decks, or restart work quickly.
  • Use Session Settings when you need to change launch, input, note, or theme behavior.
  • Use Paste and Send Safety when terminal-local paste or guarded sends behave differently between sessions.
  • Use Replay Copy and Paste for /replay ... and /ccp ... workflows.
  • Use Messaging Adapters for the Telegram reference adapter, setup/discovery steps, bounded inbound actions, and operator expectations around remote status/stop/retry/replay.
  • Use Workspace Library for saved connection profiles and workspace presets.
  • Use Trusted-Local Control for single-user multi-device takeover and layout recall.

Operating Model

  • ptydeck is optimized for a single-user local runtime with multiple sessions and decks.
  • Handbook reference pages are generated from code and contracts.
  • Handbook guide pages stay short and link back to the generated reference instead of duplicating field-level truth.
